# Nima Aksoy Today Chrome Web Store Listing

## Name

Nima Aksoy Today

## Short Description

A local-first new tab dashboard with calendar, Persian dates, Toman currency, private note, Radar, Prompts, and news.

## Detailed Description

Nima Aksoy Today replaces your Chrome New Tab page with a focused daily dashboard.

It brings together a combined Gregorian and Persian calendar, a date converter, Toman-based currency conversion, a private personal note, Radar project links, useful prompt links, and the latest public news from Vahid Online.

The extension is designed as a new-tab dashboard, not as a server account. Personal note content and preferences are stored locally in Chrome storage on your device.

Highlights:

- Combined Gregorian and Persian calendar
- Month and year calendar views
- English and Persian interface
- Gregorian to Persian and Persian to Gregorian date converter
- Toman currency converter
- Private local Personal Note
- Radar Updates and Prompts collection links
- Latest public news, refreshed hourly while the tab is open
- No account required
- No personal note upload

## Privacy Summary

Personal Note, language, and panel preferences stay in Chrome storage. The extension fetches public currency and news data from `nimaaksoy.com`, but does not send personal note content to a server.

## Permissions

- `storage`: saves local note, language, and panel preferences.
- `https://nimaaksoy.com/*`: loads public currency and news data from the website API and opens Nima Aksoy links.
