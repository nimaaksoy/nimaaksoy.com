## Common patterns across all samples

- **Hook in bold opens the description.** One line. Emotional or provocative.
- **Short paragraphs** (2–4 lines). Reader is scanning, not reading.
- **One bulleted list per description** — usually titled "Inside this book:" or "What you'll learn:" for nonfiction; "This book includes:" or "Perfect for readers who love…" for fiction.
- **Italic close** ties the book to a reader expectation. Use to clarify genre/audience.
- **No URLs, no testimonials, no review requests, no promotional language.**
- **No mention of "Kindle Unlimited", "KDP Select", or other Amazon programs** in the description (rule).

---

## Description checklist

Before submitting, every description should pass:

- [ ] Under 4,000 characters (including HTML tags).
- [ ] Opens with a bold hook of 1 sentence.
- [ ] Contains 1–2 short paragraphs of setup.
- [ ] Contains 1 bulleted list (3–5 items).
- [ ] Closes with a tone-setting sentence — italic, often genre-positioning.
- [ ] Zero URLs.
- [ ] Zero testimonials or review quotes.
- [ ] Zero review requests.
- [ ] Zero promotional or time-sensitive language ("free", "limited time", "just released").
- [ ] Zero references to specific authors, titles, or trademarks you don't own (genre/subgenre is fine).
- [ ] Zero mentions of Amazon programs.
- [ ] HTML is valid and uses only KDP-supported tags (`b`, `i`, `u`, `br`, `p`, `h4`, `h5`, `h6`, `ul`, `ol`, `li`).
