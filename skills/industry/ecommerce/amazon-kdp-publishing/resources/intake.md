# KDP intake — questions to answer before any work

Run this **before** opening any other file. KDP's correct workflow branches early; the wrong fork compounds.

Mark each answer in your scratchpad. Don't proceed past Question 9 until all are answered.

---

## The 9 intake questions

### Q1 — Book type

- [ ] Fiction (novel, novella, short fiction collection)
- [ ] Nonfiction (how-to, memoir, business, self-help, technical, academic)
- [ ] Children's (picture book, chapter book, middle-grade)
- [ ] Low-content (planner, journal, notebook, workbook)
- [ ] Photo-heavy / color (cookbook, art book, photo book)
- [ ] Other (comics, fixed-layout, box set)

→ If anything but standard Fiction / Nonfiction, also read `resources/special-cases.md`.

### Q2 — Format scope (for this launch)

- [ ] Kindle only
- [ ] Kindle + paperback **(recommended default for first launch)**
- [ ] Kindle + paperback + hardcover
- [ ] Paperback only
- [ ] All formats including audiobook (ACX is a separate platform — out of scope for this skill)

→ More formats ≠ more sales early. Default `[Kindle + paperback]` unless the user has a specific reason.

### Q3 — Primary marketplace

- [ ] Amazon.com (US) **(recommended default)**
- [ ] Amazon.co.uk
- [ ] Amazon.de / .fr / .it / .es / .nl (EU)
- [ ] Amazon.ca / .com.au
- [ ] Amazon.co.jp
- [ ] Amazon.com.br / .com.mx / .in
- [ ] Multi-marketplace global

→ Optimise one marketplace first. Categories, royalty thresholds, and ad strategy all differ by marketplace.

### Q4 — Interior color

- [ ] Black ink, white paper (cheapest)
- [ ] Black ink, cream paper (slight premium feel)
- [ ] Standard color
- [ ] Premium color (highest cost, photo-quality)

→ Color jumps printing cost 4×–10×. Required for photo books, cookbooks, picture books, art books. Avoid for standard trade.

### Q5 — ISBN strategy

- [ ] Free KDP ISBN (imprint = *Independently published*, locked to KDP)
- [ ] Own ISBN (your imprint, reusable on IngramSpark/D2D/etc.)
- [ ] No ISBN (Kindle eBooks and low-content books only)

→ Free is fine if KDP is your only platform. Buy your own if you want a real imprint name on the listing or plan to go wide.

### Q6 — Kindle exclusivity

- [ ] Enroll in **KDP Select** (90-day Kindle-exclusive; gets KU page reads + free promotions + Countdown Deals)
- [ ] Go **wide** (sell Kindle on Amazon and EPUB on other stores via Draft2Digital / direct)

→ KDP Select if your readers are on Kindle and you have no other ebook presence. Wide if you already have audience elsewhere.

### Q7 — Where are you in the process?

- [ ] Idea / outline only — start with market research (Step 1).
- [ ] Drafting the manuscript — work on outline + cover concept in parallel.
- [ ] Manuscript complete, no cover yet — focus on cover + metadata.
- [ ] Manuscript + cover ready, not yet uploaded — focus on metadata + preview/proof.
- [ ] Already published, optimising — focus on metadata + ads + reviews.
- [ ] Already published, got KDP rejection — go straight to `resources/troubleshooting.md`.

### Q8 — Budget tier

- [ ] **Tight** (<$200) — DIY cover (Canva/Affinity), DIY edit, free KDP ISBN, no paid promo. *Realistic outcomes: smaller launch, learning project.*
- [ ] **Standard** ($200–$1500) — pro cover ($300–800), copy edit + proofread ($300–800), small ad budget. *Realistic outcomes: viable first book.*
- [ ] **Pro** ($1500–$10000) — pro cover + interior, full editing ladder, BookBub-tier promo, own ISBN. *Realistic outcomes: competitive launch.*

→ A skill can't print money. Be honest with the user about what their tier supports.

### Q9 — Existing assets

- [ ] Final manuscript? Y/N — format?
- [ ] Final cover art? Y/N — Kindle-ready? Print-wrap-ready?
- [ ] Author photo + bio? Y/N
- [ ] Email list / audience? Y/N — size?
- [ ] Previous KDP titles? Y/N — under the same author name?

## Quick decision tree

```
Is the book type standard fiction or nonfiction?
├── Yes → Continue
└── No → Read special-cases.md first

Is this the user's first KDP launch?
├── Yes → Default to Kindle + paperback, Amazon.com, $5-10/day SP ad
└── No → Skip introductory framing; jump to the specific question

Is the user budget Tight?
├── Yes → Skip developmental edit recommendation; prioritise cover + proofread
└── No → Full editing ladder available

Does the user already have a published book?
├── Yes → Focus on metadata refinement, ad scaling, series math
└── No → Full 11-step workflow from SKILL.md
```

## Don't proceed without

These three answers gate everything else:

- **Q1 (book type)** — determines if the standard workflow applies or if you need `special-cases.md`.
- **Q2 (format scope)** — determines what files and specs you'll work against.
- **Q7 (process stage)** — determines which step of SKILL.md to start at.

If those three aren't answered, stop and ask. Don't assume.
