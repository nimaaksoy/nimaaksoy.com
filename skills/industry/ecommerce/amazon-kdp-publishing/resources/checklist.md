# KDP pre-launch checklist

Walk this before hitting "Publish". Failing one item is fine; you'll catch it. Failing five and launching anyway is how books quietly underperform.

---

## Phase 1 — Market fit

- [ ] You know the **target reader** in one sentence (audience, pain, goal).
- [ ] You've reviewed the **top 20 books** in the exact subcategory you'll publish into.
- [ ] You've read **3-star reviews** of at least 10 of them and noted the recurring complaints.
- [ ] The niche **scorecard total is ≥ 30/50** (see `market-research.md`).
- [ ] You can name **3+ competing books** that prove demand and **1+ gap** your book fills.

## Phase 2 — Manuscript

- [ ] Manuscript is **complete and proofed** by you, plus at least one other set of eyes.
- [ ] **Beta readers** have responded; you've acted on consistent feedback.
- [ ] A professional **copy edit or proofread** has run (or a free alternative — but at minimum two independent passes).
- [ ] Front matter is complete: title page, copyright page, dedication (optional), TOC (Kindle: hyperlinked).
- [ ] Back matter is complete: about the author, **honest review request** (one line), preview of next book (if series), other-titles list.

## Phase 3 — Ebook files

- [ ] EPUB / KPF / DOCX **validates in Kindle Previewer** without errors.
- [ ] Hyperlinked TOC works correctly on phone, tablet, and e-reader views.
- [ ] Chapter breaks render correctly.
- [ ] No widows / orphans on key opening pages.
- [ ] Kindle marketing cover: **2560 × 1600 px, RGB, ≤ 5 MB JPEG**.
- [ ] Internal cover image present, ≥ 1200 px on a side.
- [ ] If cover is mostly light: thin border added.

## Phase 4 — Print files

- [ ] Interior PDF matches chosen **trim size** exactly.
- [ ] If using bleed: entire file set up with bleed (0.125" beyond trim on outer edges).
- [ ] **Margins** match the page-count gutter table (see `technical-specs.md`).
- [ ] All **fonts embedded**.
- [ ] All **images 300 DPI** minimum.
- [ ] All **layers flattened**, transparencies handled.
- [ ] Page count within range for trim/ink combination.
- [ ] **Cover PDF** is one wrap (back + spine + front).
- [ ] Spine text only if 79+ pages.
- [ ] Important cover content **≥ 0.25" from trim** edge (paperback) or **≥ 0.635" from edge** (hardcover).
- [ ] Cover images **CMYK**, no embedded color profile.
- [ ] Title and author on cover **exactly match** the metadata.

## Phase 5 — Metadata

- [ ] Title is **exact match** to cover.
- [ ] Title + subtitle ≤ **200 characters**.
- [ ] No promotional language, trademarks, junk formatting, or claims in title/subtitle.
- [ ] Description ≤ **4,000 characters** including HTML.
- [ ] Description uses **only KDP-supported HTML** (b, i, u, br, p, h4-h6, ul, ol, li).
- [ ] Description has **no URLs, testimonials, review requests, promo language, time-sensitive info, or Amazon program names**.
- [ ] **7 keyword phrases** chosen; none duplicate title/contributor/category info.
- [ ] **3 Amazon categories** chosen (broad + mid + specific).
- [ ] Series name and author name **identical** across all formats (so they share a detail page).
- [ ] Contributor names spelled consistently.
- [ ] Publication date set intentionally (don't backdate).

## Phase 6 — Rights and legal

- [ ] You **own** or are licensed for: text, cover art, interior images, translations, quoted material.
- [ ] Cover does **not infringe** another publisher's or artist's cover.
- [ ] If quoting copyrighted material: under fair use or with permission.
- [ ] **ISBN decision** made (free KDP ISBN or your own). Each print format has its own.
- [ ] **Imprint name** (if using own ISBN) matches the ISBN registry exactly — including capitalisation and spacing. ≤ 100 characters.
- [ ] Copyright registration considered (US: literary works through the US Copyright Office).
- [ ] Tax interview completed in KDP (W-9 for US, W-8BEN for non-US).

## Phase 7 — Pricing

- [ ] **Kindle royalty plan** chosen (35% or 70%).
- [ ] Kindle price **inside the chosen royalty range** (e.g. $2.99–$9.99 for 70% on Amazon.com).
- [ ] **Paperback price ≥ $9.99** to clear the 60% royalty threshold (Amazon.com). Never $9.98.
- [ ] **Hardcover price** clears the 60% threshold.
- [ ] **KDP Printing Cost & Royalty Calculator** has been run for paperback and hardcover.
- [ ] Other-marketplace prices set or set to auto-convert from primary.
- [ ] **KDP Select decision** made consciously (90-day exclusivity vs going wide).

## Phase 8 — Launch assets

- [ ] **Author Central page** set up on Amazon.com (and other marketplaces you're targeting).
- [ ] Author bio polished; author photo uploaded.
- [ ] **ARC reader list** assembled (10–20 readers).
- [ ] ARC ebooks (EPUB/PDF) ready to send.
- [ ] **Honest-review request template** drafted (no incentive, no positive-only ask).
- [ ] **Amazon Ads** campaigns drafted in Ads console (SP Auto + SP Manual keyword), not yet activated.
- [ ] Keyword list of 30–50 phrases ready for the manual SP campaign.
- [ ] Email / social launch announcement drafted.
- [ ] Cover image in formats needed for Author Central, social media, mockups.

## Phase 9 — Proof

- [ ] **Kindle Previewer** review on phone, tablet, e-reader views — no rendering bugs.
- [ ] **Physical print proof ordered** for paperback (and hardcover if releasing).
- [ ] Print proof checked for: trim accuracy, spine fit, barcode safety, interior margins, paper weight, cover finish, contrast, font readability at actual size.
- [ ] Any proof issues resolved before going public.

## Phase 10 — Post-launch readiness

- [ ] **KDP Reports dashboard** bookmarked.
- [ ] **Amazon Ads dashboard** bookmarked.
- [ ] Decision rules written down: at what ACOS will you pause campaigns? At what daily sales will you raise the price?
- [ ] Plan for **gathering reviews steadily** for the first 30 days.
- [ ] Plan for the **next book** — first launches are best capitalised on by having a follow-up announcement ready within 60–90 days.

---

## The "if any of these are false, do NOT publish" list

Some items can be fixed post-launch. Others can't — or carry rejection / brand risk that's not worth it. Treat these five as hard gates:

1. **Title and author on cover match metadata exactly.** Mismatch = quiet conversion killer + risk of cross-format split.
2. **Cover and interior pass KDP technical specs.** Rejection delays launch and burns momentum.
3. **Description has zero forbidden content** (URLs, testimonials, review requests, promo language). KDP can remove or reject your description.
4. **You hold rights to all content.** No exceptions. Cover art, quoted text, images.
5. **You've ordered and reviewed a physical proof** for the print edition. Many issues are invisible in PDF and screamingly obvious in hand.

If any of those five fails, fix it before hitting publish. The other ~70 items in this checklist are nice-to-have for a great launch. These five are mandatory.
