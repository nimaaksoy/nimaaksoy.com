# Spoken-style rewrite — formal Persian → colloquial Tehran-standard

Apply only when the user picks the **Spoken** register. Otherwise skip this entire step.

The goal is natural conversational Persian, not children's speech and not extreme regional slang. Default to Tehran-standard colloquial (`gofteari-ye Tehrani`).

## The است → -ـه pattern

In spoken Persian, the verb `است` (is) becomes a suffix on the previous word:

| Formal | Spoken |
|---|---|
| خوب است | خوبه |
| بد است | بده |
| اینجا است | اینجاست |
| اون است | اونه |
| من خوبم | (no change — already spoken form) |
| تو خوبی | (no change) |
| او خوب است | اون خوبه |
| ما خوبیم | (no change) |

For words ending in `ی`, `ا`, or `و`, use `ـست` (`اینجا` → `اینجاست`, `بالا` → `بالاست`).

For words ending in `ه`, use `ـست` (`خونه است` → `خونه‌ست`).

## What NOT to rewrite

Even in Spoken register, leave these alone:

### Proper names

Never modify a person's name, place name, or brand name.

```
صادق هدایت  → صادق هدایت  (no change)
دانشگاه تهران  → دانشگاه تهران  (no change)
```

### Technical / specialised vocabulary

If the text contains scientific, legal, medical, or programming terminology, leave it formal:

```
الگوریتم مرتب‌سازی سریع  → leave alone
معاهده وین  → leave alone
بیماری دیابت نوع دو  → leave alone
```

### Religious phrases

Always preserve:

```
بسم الله الرحمن الرحیم  → no change
الحمد لله  → no change
انشاالله  → no change (may become "ایشالا" only in extreme casual register — usually leave)
```

### Fixed expressions and idioms

Many idioms have a fixed form. Don't modernise:

```
سرت سلامت  → no change
دستت درد نکنه  → no change
خدا حافظ  → خدافظ in spoken (acceptable to convert)
```

### Quoted material

If the text contains a quote, leave the quote in its original register:

```
گفت: «من نمی‌آیم»  → گفت: «من نمی‌آیم»  (don't rewrite the quote)
```

### Titles and headings

Often formal even in spoken content:

```
فصل اول: مقدمه  → leave alone
بخش دو  → leave alone
```

## Register consistency rule

Once you rewrite a word to spoken form, **all instances of that word in the same text** should match. Don't mix:

```
Bad:  من می‌خوام برم. تو می‌خواهی بیای؟
Good: من می‌خوام برم. تو می‌خوای بیای؟
```

If a word appears 5 times in formal form, all 5 should be converted (or all 5 should stay formal).

---

## Don't over-rewrite

Spoken register doesn't mean "maximum casual." It means "natural conversational." Keep:

- Long words intact if they're naturally said long: `بیمارستان` doesn't shorten to `بیمارستون` — it stays as is.
- Polite forms: `شما` stays `شما`. Don't convert to `تو` regardless of register.
- Discourse markers in moderation: don't insert filler like `خب`, `راستش`, `یعنی` that wasn't in the original.

The goal is to make the text **read naturally aloud** — not to make it look like a transcript of a chat message.

## Register escalation chain

| Audience | Register |
|---|---|
| Legal document, news, academic | **Preserve** (don't rewrite at all) |
| Audiobook of literary work | **Preserve** |
| Professional voiceover, e-learning | **Fluent-formal** (Ezafe + numbers, but verbs stay formal) |
| Chat assistant, social media voiceover | **Spoken** (apply this table) |
| Drama, dialogue, comedy | **Spoken** + per-character tone adjustment |

---

## Verification

After rewriting, ask:

1. **Could the original speaker have said this naturally?** If no, it's over-rewritten.
2. **Is the register consistent throughout?** If not, fix the inconsistencies.
3. **Are proper names, technical terms, religious phrases, and quotes preserved?** If not, restore them.

Reading the output aloud (in your head) is the fastest check. If anything sounds awkward, revert that specific change.
