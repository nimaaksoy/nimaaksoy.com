## Workflow

Create custom logo animations with ChatGPT Images 2.0 and Seedance 2.0.

1. Use Images 2.0 to create a detailed animation sheet for how the logo should appear, including timing for each section.
2. For the first iteration, make sure the type of visuals is correct. You can upload a reference image here too.
3. In Seedance 2.0, use the animation sheet as a reference and insert a video prompt. Match the video duration to the sheet (this example is an 8 second animation).
4. Keep chatting with Images 2.0 to refine motion guidelines before the video step. Make animation guidelines clear for how something should move or morph.

## 1. Animation sheet prompt (ChatGPT Images 2.0)

Create an animation sheet for a slick logo animation for a company called NEO. The logo is a minimalist glassmorphic leaf. The sheet should show clearly a storyboard with animation lines for a slick animation, this can be complex.

## 2. Video prompt (Seedance 2.0)

Attach the animation sheet as Image1 / reference.

Create the logo animation as described in Image1 for the NEO product logo. Follow the reference exactly.

Settings used in the example: Dreamina Seedance 2.0, 8s, Omni reference, 16:9, 1080P.

## 3. Iteration tips

- Reduced total duration from ~50s to a tight ~8s logo animation
- Simplified storyboard structure (fewer steps, clearer progression)
- Switched to dark background for proper contrast and readability
- Refined animation flow with a clearer orb → leaf transformation sequence
- Added focused breakdown section to explicitly show shape morph (diagonal stretch, point formation, vein draw-in)

## Example sheet stages (from the generated NEO sheet)

1. AWAKEN 00:00–00:10
2. ENERGIZE 00:10–00:22
3. FORM 00:22–00:40
4. MATERIALIZE 00:40–00:52
5. POLISH 00:52–00:60
6. REVEAL NEO 00:60–01:05
7. HOLD 01:05–01:45
8. FADE OUT 01:45–02:00
